# BuzzQuiz stock artwork

5,064 reusable illustrations across 1,185 topic labels and 741 source sheets. The question bank includes 710 original four-choice prompts. Each linked sheet follows row-major order, from the top left. Open its adjacent JSON file for descriptions and question text. The original category portraits use the [category manifest](../src/lib/category-portraits.json).

The [research notes](quiz-categories.md) identify which subjects appeared in BuzzFeed’s historical ranking and QuizCheese’s public lists. The additional subjects extend coverage for creators.
